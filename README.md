## The mark

Two identical chevrons on a 96 x 120 grid, 24 stroke, round caps.

- Upper: `M26 20 L70 46 L26 72`
- Lower: `M26 48 L70 74 L26 100`
- Arms cross once; the crossing is cut from the lower ribbon with a mask

| File | Use |
|------|-----|
| `svg/zunia-mark-clean.svg` | Gradient mark for product UI |
| `svg/zunia-mark-current.svg` | `currentColor` mark for themed UI |
| `svg/symbol/*` | Red, amber, black, white, on-dark variants |
| `svg/logo/*` | Horizontal and stacked lockups |
| `png/icons/app/*` | App icons 16–1024 |

- **Clear space:** one chevron height on all sides
- **Minimum:** symbol 16 px · lock-up 88 px wide · print 22 mm
- **Wordmark:** Space Grotesk 700, tracking -0.065em

See `tokens.css` for the full CSS custom-property set.

## Typography

- **Space Grotesk** (400 / 500 / 600 / 700) — wordmark, headings, UI, body
- **JetBrains Mono** (400 / 500) — addresses, hashes, amounts, chain IDs

Both are open source (SIL OFL) on [Google Fonts](https://fonts.google.com/).

## Do not

- Stretch, squash, or rotate the mark
- Distort the opening angle or stroke weight
- Recolour outside the palette
- Place the mark on a background that competes with the warms
- Set the wordmark in another face or tracking
